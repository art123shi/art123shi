# Camper Van Configurator

This example demonstrates a very simple 3D camper van configurator built with [three.js](https://threejs.org/). It uses primitive shapes to approximate a camper van and allows the user to change the vehicle color.

## Usage

Open `index.html` in a web browser with internet access (required to load three.js from the CDN). Use the color picker in the top left corner to change the color of the van. Click and drag to rotate the scene.

This implementation is intentionally minimal and meant only as a starting point for a more advanced configurator.
